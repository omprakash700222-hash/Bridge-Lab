1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.

         Frontent development:--
         Frontend development is the part of web development that users interact with directly. It focuses on designing the user interface (UI) using HTML,             
         CSS and javascript.
         Real-world Example:
         On Amazon, the product images, search bar, and "Add to Cart" button are part of the frontend.

         Backend Development:--
         Backend development is responsible for the server-side logic. It processes user requests, stores data, and communicates with databases.
         Real-world Example:
         When you log into Amazon, the backend verifies your username and password and retrieves your account information.

         Full-Stack Development:--
         A full-stack developer works on both the frontend and backend.
         Real-world Example:
         A developer creating a complete online shopping website, including the user interface, login system, payment processing, and database.

3. Describe how a browser requests and displays a web page from a web server.
          Steps:
          (1)User enters a website URL.
          (2)Browser finds the server's IP address using DNS.
          (3)Browser sends an HTTP/HTTPS request.
          (4)The web server receives the request.
          (5)If needed, the server accesses the database.
          (6)The server prepares HTML, CSS, JavaScript, and other files.
          (7)The server sends the response back.

9. Research and list five web browsers. Explain how rendering engines differ between them.

Browser	Rendering Engine
Google Chrome	Blink
Microsoft Edge	Blink
Mozilla Firefox	Gecko
Apple Safari	WebKit
Opera	Blink
Rendering Engines

A rendering engine converts HTML, CSS, and JavaScript into the webpage displayed on the screen.
Blink: Used by Chrome, Edge, and Opera. Fast and widely supported.
Gecko: Used by Firefox. Independent engine with strong standards compliance.
WebKit: Used by Safari. Optimized for Apple devices.
